# 代码逻辑与后续主界面

## 依赖方向

桌面主进程负责文件、模型网络请求和密钥保护；渲染界面只通过 `window.kongxiaozhu` 的固定方法调用。独立计算线程加载 `src/core`，仿真和整定不阻塞界面。

`src/app` 管理软件外壳、功能注册和当前入口；`src/ui/control-lab` 管理控制实验交互；`src/core` 管理数学模型和指标；`desktop/services` 管理数据与 AI。计算模块不依赖 React 或 Electron。

## 后续添加主界面

先在 `src/app` 添加主界面视图，再从 `featureRegistry.js` 生成入口。控制实验入口保留稳定的模块 ID。首页点击进入实验模块，模块不自行实现全软件导航。新增功能在注册表中添加 ID、名称和入口组件，并定义自己的状态，不复用实验模块的临时字段。

离开模块时先保存。持久实验数据和暂时页面状态分开，返回时恢复选中的实验。视觉调整优先修改主题变量、通用组件和页面布局，不修改计算结果以配合展示。

## 数据一致性

0.1.2 的工作台采用固定高度的桌面分区：左侧参数独立滚动，右侧在响应、比较、复盘与历史标签之间切换。标签面板始终挂载，通过 `hidden` 隐藏，避免切换时丢失预测草稿；实验切换仍使用独立组件身份。布局规则集中在 `workbench-layout.css`，不改计算与数据服务。

`AiAssistant.jsx` 与 `ai-assistant.css` 独立管理悬浮入口及非模态侧窗。打开侧窗仍能操作参数；关闭仅隐藏，不销毁当前草稿和提案。设置模态窗优先处理 Escape。AI 候选仍走既有验证和应用流程，侧窗只提供进入“方案对比”的入口。

实验配置改变递增 `version`，运行保存自己的配置快照和 `configVersion`。异步 AI、整定、仿真请求关联请求版本；旧结果可以保留为历史，但不得覆盖新配置。比较通过 `conditionKey` 核对模型、初态、信号、扰动、窗口及评价阈值。控制器是被比较变量。

`comparisonRunId` 单独记录固定对照，`lastManualRunId` 记录最近完成的手动运行。自动预览和同参数手动重跑保持对照；不同参数的有效手动运行才推进。运行与指针在同一状态提交中保存，旧异步结果不能改动指针。旧实验缺字段时只迁移一次；不同评价条件暂不叠加，不能为了补一条紫线而自动切换数据来源。

AI 候选来自工具执行结果，模型只能提出受限控制器参数。每组建议必须实际仿真；界面确认应用时按当前条件再次计算。自然语言目标只生成提案。算法结果、模型解释和用户结论在实验记录里各有来源。

## 桌面与交付

主窗口启用沙箱与上下文隔离，不向网页暴露 Node；不加载远程网页，拒绝任意导航和权限请求。模型请求在主进程，计算在线程中。Windows 系统保护密钥，本地实验数据为可备份 JSON。

打包依据 `scripts/runtime-manifest.json` 的明确文件清单；复制锁定版本的 Electron 运行时、构建界面和计算运行依赖。发布清单记录实际文件大小及 SHA-256。开发依赖、测试数据、环境变量文件、个人密钥不进入软件目录。

## 2.2.0 全局音频与阵列入场

音频生命周期属于 App 外壳，不属于主页 iframe 或实验模块。主页仅通过窗口身份与内容白名单验证的消息请求声音、修改偏好；父层回传完整声音状态，两处设置同步。跨页隐藏三维主页不暂停或重建音频。配乐保持同一循环与起播时间；设置改变以音量渐变避免突变，关闭总声音立即静音。仅在应用真正销毁时释放音频资源。配乐及程序合成音效均来自本地资源，打字声独立合成并限频，不读取或录制输入内容。

入场单独驱动现有场景的 cinematic 轨迹，从信号匣阵列揭示开始到稳定主页结束，不载入原 Logo 片头或旧 GLB。减少动态和跳过立即落到完整最终状态。工作台返回不重新进入入场阶段。音频、入场与控制计算均彼此独立。

## 3.0.0 欢迎、配乐衔接与品牌资源

`src/app/WelcomeScreen.jsx` 和 `welcome-motion.mjs` 从用户确认的工作区 `output/design/logo-welcome-01/index.html` 提取欢迎设计，画面依次为复合波、分量、阻尼响应和收敛环。该 Canvas 演示有自己的时间轴，不调用 `src/core`、不读取实验状态；四阶段用于品牌表达，不构成真实仿真或“傅里叶分解产生阻尼”的计算结论。

App 外壳依次放行欢迎、现有阵列入场及主页。欢迎显示时底层外壳不可交互，主页等待激活后才开始入场。欢迎正常播放约 8 秒，再淡出约 320 ms；跳过立即完成且不把同次 Esc 传给底层入场，减少动态直接完成。页面隐藏时暂停欢迎时钟，恢复后继续；卸载清理动画帧和事件监听，完成回调只发送一次。只读的 `window.__kxWelcome.getState()` 用于核对阶段和计时，不提供改写接口。

音频仍由 App 外壳统一管理。欢迎只通过 `onCue` 请求白名单内少量合成音效；不创建局部音频实例。`musicReady` 同时要求欢迎完成与主页阵列入场完成，主页就绪消息经来源窗口及内容校验后才开启背景配乐。静音与分项偏好独立于这道启动条件，不能因完成欢迎而自动取消静音。进入实验台、返回主页时保留同一音频服务与播放进度。

`public/brand` 保存经确认的 SVG、PNG 和多尺寸 ICO，`src/ui/BrandMark.jsx` 供软件内品牌显示使用。Windows 打包流程将相同 ICO 写入本次发行程序，安装器和桌面快捷方式引用同一图标；不得为换图标修改已归档的历史发行包。资源来源与开发时再生成方法见 `public/brand/README.md`。应用版本为 `3.0.0`，计算引擎仍为 `1.0.0`，存储格式与计算条件校验不变。
