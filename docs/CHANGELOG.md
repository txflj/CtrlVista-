# 版本记录

## 3.0.0 · 2026-10-29

- 接入用户确认的收敛环 Logo 与约 8 秒欢迎段，来源为工作区 `output/design/logo-welcome-01`；保留复合波、分量拆分、阻尼响应、收敛环定格四阶段设计。
- 欢迎为独立品牌视觉演示，不读取实验结果、不修改控制计算，也不将波形分解描述为实际闭环收敛原因。
- 启动顺序为欢迎、原有自研信号匣阵列入场、主页；两个阶段可分别跳过，减少动态直接进入主页，返回主页不重播。欢迎在窗口隐藏期间暂停计时。
- 欢迎仅使用少量现有合成音效，欢迎及阵列入场期间不播放背景配乐；主页准备就绪后才播放，随后在主页与实验台之间连续循环。沿用并记住静音、分项开关与音量。
- 将程序、安装器、窗口、桌面快捷方式及软件内品牌图标替换为同一收敛环 Logo；资源与来源说明随源码保留。
- 应用版本为 `3.0.0`，计算引擎仍为 `1.0.0`，实验数据格式不变。本版验证及安装结论以实际记录为准，历史参赛报告不随版本号自动改写。

## 2.0.0 · 2026-10-28

- 三维实验入口改为本项目编写的程序化信号匣几何；阵列与抽取后的详情共享同一几何定义，采用平顶大矩形屏、顶部信息条、L 形金属边和右上角标签片。
- 信号匣用独立合成信号演示傅里叶分解：从 2 秒、256 个采样点计算真实 DFT，识别三个主要分量的频率、幅值和相位，再在同一时间轴重建波形并计算误差。
- 屏幕分解过程与右侧解析文字同步；明确标注这是教学合成信号，不把频谱或分量波形作为 PID 实验的实际结果。
- 移除 360° 查看入口，发行不再包含 `archive-cassette.glb` 和 `archive-assembly.glb`；保留信号匣浏览、抽取与归位。
- 继续保留 RhineLabUI 上游代码的作者署名与 MIT 许可，更新实际复用范围；新的几何不意味着全部界面与交互均为本项目原创。
- 应用版本更新为 `2.0.0`；控制计算引擎 `ENGINE_VERSION` 保持 `1.0.0`，实验存储格式与 API 服务边界不变。实际测试和发行检查结果见 `VALIDATION.md`。

## 0.1.1 · 2026-10-27

- 修复自动计算后再次手动运行相同参数，会把紫色上一方案替换为蓝线重复结果的问题。
- 紫线改为“固定对照”。首次有效结果初始化对照，自动预览保持它不变；手动完成不同配置时，对照推进为此前的手动结果。同参数重跑不会推进。
- 固定对照和最近手动运行指针随实验保存、复制与导入导出。旧实验首次打开时迁移，跳过当前参数的重复计算。
- 模型、目标、扰动等评价条件不同时暂不叠加对照，仍保留对照记录；紫色保留给固定对照，候选方案使用其他颜色。
- 手动运行取消待触发的自动计算，运行中的手动请求不被同版本自动任务抢占。旧请求不能改变当前对照。
