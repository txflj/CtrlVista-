# 控小助计算引擎说明与验证记录

计算版本：`1.0.0`。本说明对应当前项目 `src/core/`，验证日期为 2026 年 10 月 27 日。

## 文件与公开接口

`index.mjs` 导出 `ENGINE_VERSION`、`CASES`、`createCaseConfig`、`validateConfig`、`conditionKey`、`simulate`、`autotune`、`compareRuns`。调用结构见项目根目录 `IMPLEMENTATION_CONTRACT.md`。

| 文件 | 职责 |
| --- | --- |
| `config.mjs` | 配置校验、条件键、版本与 ID |
| `numerics.mjs` | 状态空间、极点、矩阵指数、分段状态转移 |
| `engine.mjs` | 完整仿真记录与复算比较 |
| `metrics.mjs` | 指标、目标判定与原因 |
| `cases.mjs` | 三个引导实验、一个综合挑战及参考控制器 |
| `autotune.mjs` | 有限预算、固定种子的参数搜索 |

计算函数在本机运行，不调用模型 API。AI 候选、手动运行和自动整定均复用 `simulate`；AI 的自然语言说明不能替换计算结果。返回记录使用普通对象和普通数组，无效数值指标用 `null` 表示。

## 模型范围和数值边界

被控对象为连续、单输入单输出、严格真有理的 1—3 阶传递函数，系数按降幂排列。分母最高次系数绝对值至少为 `1e-12`，原始系数绝对值最多为 `1e8`；直流增益须为有限正数。使用 `ml-matrix` 特征值分解检查对象及闭环极点，极点实部必须严格小于 `−1e-10`。非常接近虚轴的对象按当前数值边界拒绝，而非作严格数学不稳定的证明。

首版不支持纯滞后、离散系统、多输入多输出、非线性、执行器饱和、硬件控制及噪声模型。传递函数零点没有限定在左半平面；只要对象满足上述范围，仿真仍按原分子系数计算。

控制增益须在声明的范围内，且为 `0—100000`；滤波时间常数范围为 `0.00001—100 s`。仿真时长不超过 `3600 s`，步长至少为 `0.00001 s`，采样数含预留事件点最多 `24001`。状态绝对值超过 `1e14`，或矩阵指数超过实现的缩放范围时，返回 `numerical_error`，不伪造完成结果。上述输入范围不是对任意病态系数均具有高相对精度的承诺。

## 状态坐标与控制律

将分母归一化为：

```text
D(s) = s^n + a[n−1] s^(n−1) + ... + a[0]
N(s) = b[n−1] s^(n−1) + ... + b[0]
```

低阶分子在高次项补零，同时除以原分母最高次系数。使用可控标准型：

```text
x1' = x2, ... , x[n−1]' = xn
xn' = −a[0] x1 − ... − a[n−1] xn + u + d
y = b[0] x1 + ... + b[n−1] xn
```

`initialState` 对应上述标准型状态，不自动解释为“输出及其导数”。例如 `G(s)=1/(0.5s+1)` 归一化后 `y=2x1`，若希望 `y(0)=0.2`，需令 `initialState=[0.1]`。空数组表示各状态为零。`signal.initial` 是目标信号在阶跃前的值，不会把对象自动放置到该目标的平衡状态。

控制采用以下形式，微分作用于测量值：

```text
e = r − y
z' = e
v' = (y − v) / tf
u = kp e + ki z − kd (y − v) / tf
```

`integralInitial` 是积分状态 `z(0)`；`filterInitial` 是低通测量状态 `v(0)`。P 模式不启用积分、微分；PI 模式不启用微分。增益为零时，也不加入对应的 I／D 状态，因此不会制造无作用状态带来的假零极点。参考值阶跃不会直接进入微分项，避免设定值的微分冲击。

控制输出不裁剪。`controlPeakMax` 仅为评价预算，因此高峰值方案会失败，但曲线仍保留真实计算出的未裁剪输出。执行器饱和与抗积分饱和算法尚未实现。

## 分段仿真与来源

合并对象和控制器状态后，每个恒定输入区间均满足：

```text
X' = A X + Br r + Bd d
```

对增广矩阵 `[A Br Bd; 0 0 0; 0 0 0]` 计算矩阵指数，获得每段的状态转移。指数采用 13 阶 Padé 近似与缩放平方，使用 `ml-matrix 6.15.1` 做矩阵运算、线性方程求解和特征值分解。项目中的矩阵指数实现依据 Higham 的公开算法；并未宣称原创该算法。`ml-matrix` 的 `Matrix.exp` 是逐元素指数，故不用于系统状态转移。[Higham，2005，作者所在机构的论文条目](https://eprints.maths.manchester.ac.uk/634/)；[ml-matrix 官方仓库与 API 入口](https://github.com/mljs/matrix)。

在常规采样网格外，额外插入目标阶跃、扰动开始、扰动结束及仿真终点。各段使用其左端的输入值推进状态；事件后显示新输入，状态连续。扰动 `d` 加在对象输入端：`duration=null` 表示持续扰动，正值表示持续相应时长后撤去。事件不要求对齐 `dt`。控制峰值同时检查事件的左右极限。

“准确分段”表示线性恒定输入段采用矩阵指数推进，仍存在 IEEE 双精度舍入及矩阵运算误差；它不意味着符号计算或无限精度。

## 指标定义和达标判定

目标误差带半宽为：

```text
band = max(absoluteTolerance, relativeTolerance × referenceScale)
```

`referenceScale` 必须为正数，默认取归一化满量程 `1`；它不是自动取目标值，因而零目标也有明确误差带。相对误差带乘积溢出时拒绝配置。

| 指标 | 定义及范围 |
| --- | --- |
| `overshoot` | 目标阶跃开始到扰动发生前，沿阶跃方向超过目标值的最大量，除以目标变化幅度，乘 `100`。这是相对目标的超调，非相对闭环最终值的传统百分比超调。零阶跃幅度时为 `null`。 |
| `settlingTime` | 跟踪阶段内，最后一次处于目标误差带外之后，进入误差带且在剩余观察时间始终处于带内的首个采样时刻，减去阶跃时刻；还须满足最短 `holdTime`。 |
| `steadyError` | 稳定闭环在所有给定事件之后最终恒定输入下，由 `A X∞ = −Br r∞ − Bd d∞` 解出平衡状态，计算 `abs(r∞−y∞)`。不是最后采样点误差。 |
| `recoveryTime` | 从扰动开始到观察终点，按同样误差带和保持规则计算，时间从扰动开始计；若整个采样区间都在带内且满足保持时间，可为 `0`。 |
| `controlPeak` | 整个观察窗口内未裁剪控制输出绝对值的最大采样值，并包括输入事件左右极限。 |
| `maxDisturbanceDeviation` | 扰动开始后采样输出相对目标的最大绝对偏差。 |
| `tailError` | 最后采样点相对目标的绝对误差，仅作为观察值，与理论稳态误差分开。 |

目标跟踪在扰动开始时截止；恢复阶段包含持续扰动或脉冲扰动的撤去过程。如果扰动发生在阶跃之前，独立跟踪／恢复评估可能不足，返回相应未知指标和提示。有限脉冲的理论最终扰动为零，即使其撤去时刻超出了当前观察窗口；此时理论稳态与当前末点可能明显不同。时间阈值比较允许 `1e-10 s` 的舍入余量，避免减法产生的机器精度尾差把恰好达到阈值的结果误判为失败。

每个条件分别返回 `pass`、`fail` 或 `unknown`。任一必需条件失败则整体失败；没有失败但存在未知则整体未知；全部必需条件通过才达标。对应阈值设为 `null` 可以关闭该可选条件，控制输出预算不可关闭。短窗口还未观察到满足保持要求时，不把调节时间强行填写为仿真时长；如果已经观察到规定截止时刻仍在带外，或已过完整判定窗口，则相应时间条件失败。

调节时间不做跨采样插值，分辨率取决于网格。超调、控制峰值、最大偏差仍可能漏掉采样间的窄峰。闭环最快极点模长乘以 `dt` 大于 `0.5` 时会提示步长偏粗；该提示不是严格误差界。需要更精确峰值时，应减小步长并比较结果。窗口内“保持”不能证明窗口之后永不越界，当前引擎不提供连续时间峰值证明或鲁棒稳定性保证。

## 自动整定的可复现范围

自动整定是有界启发式搜索，默认预算 `48` 次，允许 `1—160` 次，默认种子 `42`。使用固定的 32 位伪随机序列；预算计入不稳定或数值失败的实际仿真。固定范围导致无法构造新参数时，可以提前结束并返回真实计算次数。

搜索保持当前控制器类型和 `tf`，只调整该类型启用的 `kp`／`ki`／`kd`。初始候选包括当前参数、同案例且同类型的已提供参考控制器参数、若干倍数与单维变化；之后结合当前较优方案的扰动与全范围随机采样。**参考控制器作为公开初始种子，不是搜索独立发现的成果**。即使用户修改了模型、目标或滤波时间，参考增益也必须用当前完整配置重新计算；参考项自身的 `tf` 不覆盖当前 `tf`。

评分综合达标状态、相对阈值的指标及绝对误差积分，偏好达标方案；最多保留三个完成计算的候选。它不是全局最优证明，也不是自动选择控制器结构的算法。没有找到达标方案时，报告预算、范围和失败情况，不能推断数学上不存在解。原始配置不会被搜索修改。数值结果可重复，记录 ID 与创建时间是审计元数据，不要求重复。

## 复算容差与条件一致性

`conditionKey` 对模型、仿真窗口与初态、目标、扰动、指标定义和阈值、参数范围生成稳定序列化字符串，排除控制器和展示标题。比较方案须使用相同条件键；复现同一次运行还须使用相同控制器。

`compareRuns` 检查计算版本、真实配置、记录的条件键、控制器、运行状态、判定、指标与六条完整采样数组。指标及曲线的一般数值容差为：

```text
abs(a−b) ≤ 1e−8 + 1e−6 × max(abs(a),abs(b))
```

调节和恢复时间指标容差为两个记录步长的较大者加 `1e-9 s`；曲线网格仍须满足一般数值容差且长度一致。两个指标均为 `null` 可视为一致。缺失记录、损坏字段、超出容差或配置不一致不能通过。该比较是复现一致性检查，不是对算法正确性的独立认证。
