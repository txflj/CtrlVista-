## 公开范围

公开副本包含当前源码、依赖锁文件、教学案例、测试、构建脚本、文档和验证记录。本地回退用的旧提交与旧标签继续保留，但不批量推送；历史版本曾包含的旧第三方 GLB 不进入首次公开历史。

内部参赛报告目录不进入公开副本，因其对应历史版本且包含赛务材料。用户设置、实验目录、密钥、缓存、依赖和完整安装目录不进入代码仓库。验证记录中的开发机绝对路径替换为通用占位符；检查结果、时间和指标保留。公开副本经过路径与凭据模式检查，这不等同于第三方安全认证。

3.0.0 安装包对应已验收的程序版本，不因添加开源文档而重编译或替换已发布程序。Windows 二进制包中自带的 LICENSE 属于 Electron，项目自身许可通过仓库根目录 LICENSE 与发布附件提供；两者不能混为一谈。新的源码归档会包含项目 LICENSE、NOTICE 与第三方说明。

公开仓库的 v3.0.0 标签指向首次公开快照。本地开发仓库中已有的 v3.0.0 标签仍指向当时交付提交，保持不移动。后续公共源码从公开仓库继续维护，不将本地旧模型历史合并进公共主线。

首次公开仅包括当前代码授权，不把既有控制方法、第三方代码或配乐表述为自主原创。AI 辅助开发及验证边界见 docs/VALIDATION.md。
