# 2.0.0 主页与工作台 UI 架构

文件名沿用 1.0.0 的文档入口，以下主体说明当前 2.0.0 实现；历史范围见文末。

## 视觉与范围

沿用控小助的蓝灰深色体系，适度加深背景、提升文字层次，以细线、较小圆角、简洁按钮和分区留白参考 RhineLabUI。工作台保留蓝色当前响应、紫色固定对照和原指标状态含义。旧“控”图标保留，本版不将未获确认的图标设为应用图标。

主页直接进入信号匣阵列。保留选择、拖动惯性、抽取、归位、详情解析过渡和材质明暗切换；没有音频、开场片头及启动授权表演，2.0.0 移除 360° 查看入口。两个分组承载四个真实案例，背景重复信号匣是空间排列，不代表额外实验。

信号匣几何由本项目程序化生成：平顶大矩形屏、顶部信息条、L 形金属边与右上角标签片。阵列（array）和详情（detail）共享同一几何定义，抽取只改变位置、显示与材质状态，避免两处外观漂移。旧版两份 GLB 不再作为当前运行资源或随本版发行。

屏幕展示独立合成信号的傅里叶分解，右侧解析文字跟随分解进度显示。信号数据来自 `signal-fourier.mjs`：2 秒内 256 个均匀采样点覆盖半开区间 `[0, 2)`，计算单边 DFT 频谱并提取三个主要分量的频率、幅值和正弦相位，在同一时间轴重建波形并计算误差；每个案例的结果生成后缓存。该演示不读取或替代控制实验运行结果，不能将其频谱解释为相应 PID 实验的实际响应。

主页作为独立构建入口 `homepage.html`，在本地 iframe 中运行。iframe 没有桌面 preload 权限；父窗口验证消息来源窗口及命令白名单，案例只允许 motor、temperature、position、challenge。它不能直接读写文件或访问模型密钥。

主页负责请求进入实验、实验库、记录、设置、开放验证或继续当前实验。React 外壳负责切换和保存，计算、搜索、AI 服务、实验存储继续使用原实现。返回主页先等待当前保存完成；工作台保留挂载，以保留草稿和当前状态。隐藏的 AI 侧窗不会覆盖主页。

三维场景在工作台显示期间停止更新。恢复时重置动画时钟并重新计算尺寸，零尺寸窗口不得污染相机参数。默认流畅档位保留当前信号匣、材质和交互，关闭高成本景深与环境遮蔽采样；需要更精细画质可在设置调整。系统减少动态效果设置在没有个人偏好时生效。

三维场景初始化或渲染失败仍应提供可操作的实验详情和列表入口；三维展示不是使用本地计算的前提。主题与收藏保存于主页本机设置；实验记录继续使用桌面数据服务。应用版本为 `2.0.0`，`src/core` 的 `ENGINE_VERSION` 保持 `1.0.0`。

## 来源与验证

复用并改编 RhineLabUI 的 MIT 许可代码，固定提交为 `12cc5e4013acb9408f753ff71de6b8492299b7c8`。2.0.0 替换其几何资产，仍保留场景、浏览、抽取归位、材质、文字与内容转场等上游代码；不能因此将全部 UI 或交互宣称为本项目原创。未打包其旧 GLB、音频、外部字体、游戏原文和游戏标识；保留原作者署名、第三方许可及改编说明。具体范围见 `third-party/RhineLabUI/NOTICE.md`。

主页专项使用 `scripts/homepage-check.mjs` 检查真实 Electron 内的入口、场景与工作台连接；傅里叶数值核对位于 `tests/signal-fourier.test.mjs`。工作台完整流程和布局测试继续独立运行，分别验证功能、窗口尺寸、状态保留。实际完成的检查及结果以 `VALIDATION.md` 和对应证据文件为准。线上模型、学生试用和第二台电脑不属于这些本地自动化证据。
