## 视觉与交互

主视觉是 64 片金属片组成的响应带：横向为时间，片的高度来自标准二阶系统单位阶跃响应。改变阻尼时，雕塑与二维响应采用同一解析函数；雕塑的插值仅作显示过渡。固定固有频率为 1.8 rad/s，显示时间范围为 0～6 s。这是主页演示，不是用户当前实验或计算服务输出。

深色方案：背景 #17212c，表面 #1d2a38，文字 #e7edf3，次级文字 #a4b3c4，交互强调 #a2bfe1，结构线 #354556。附带浅色仪器配色和陶瓷材质选项，供审阅时比较，并不改变正式软件主题。

字体：中文标题用 Microsoft YaHei UI 的常规字重，正文用同字族与 Segoe UI；数字与辅助英文用 Bahnschrift / Consolas。强调标题与正文的尺寸差，避免装饰性微型文字。左侧为明确入口，右侧为响应雕塑，下面放阻尼操作及实验索引。

支持拖动旋转、侧视、复位、阻尼滑块、图标大图与 48/24 像素预览、实验选择与流程说明。实验按钮在预览中打开流程介绍，不连接本机实验。图标将收敛轮廓简化为三条线，仍为待审核草案。

没有持续自动旋转或自动播放声音。减少动态效果设置开启时，阻尼变化直接更新；离开可见区域不持续渲染。WebGL 或 CDN 不可用时显示二维层片回退，并明确标注。
