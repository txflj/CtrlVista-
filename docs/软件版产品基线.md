# 控小助软件版产品基线

初次确认日期：2026-10-27；当前应用版本：3.0.0，增量更新日期：2026-10-29。当前源码根目录为本文件上一级目录的上一级。此基线将原网页方案改为 Windows 本地桌面软件；不需要用户部署网站。

## 产品与范围

面向自动化及相关专业学生的控制实验工作台。体验为选择任务、预测现象、调参、观察真实仿真、请求 AI 提出并验证建议、比较方案、保存和复盘。所有实验在电脑内完成，不涉及实物实验。

三个引导实验为电机调速、机械定位、温度调节，另有综合挑战。场景使用明确假设的教学模型，不宣称等同真实工业设备。支持 P、PI、PID，PID 的微分对测量值作用并过滤。自定义对象限定连续、稳定、单输入单输出、严格真有理、正稳态增益、最高三阶。首版不含纯滞后、离散、多变量、硬件采集、执行器饱和和抗积分饱和。

实验库、实验工作台、我的实验、开放与验证为控制实验模块的入口。软件外层单独提供功能注册表，三维主页通过实验入口进入该模块；其他功能模块不属于当前范围。离开和返回模块应保留实验状态。

## 功能与交互

- 实验库展示任务、学习目标、模型假设和实验入口。引导与自由模式共享同一实验状态。
- 工作台允许修改模型、初态、阶跃、扰动、评价阈值和控制器。编辑后保留历史运行，明确当前配置和历史结果的关系。
- 曲线使用实际仿真数据，展示目标、输出、误差、控制作用。超调、调节时间、稳态误差、恢复时间、控制峰值采用公开定义；不能判定时显示原因。
- AI 主要接入 DeepSeek，提供商、地址、模型、超时可配置。密钥只在软件设置填写，通过 Windows 系统安全存储保护，不进入实验包。
- AI 请求最多验证三组候选，调用同一计算引擎，保留调用记录和指标。解释依赖真实工具结果，用户明确应用后才改变当前方案。过期候选在当前条件下重算。
- 自然语言目标先生成可检查提案，不直接修改配置。缺失参数由用户补充。
- 自动整定独立入口，给出搜索预算、种子和结果。未找到达标解不等于数学上无解。
- 比较必须使用一致评价条件，同时呈现收益与代价。参考控制器属于案例内容，自动整定和 AI 结果必须标明来源。
- 运行、候选、预测、观察、笔记与复盘保存至当前 Windows 用户的数据目录。导出 JSON 实验包、CSV 曲线、HTML 小结；导入创建新记录，支持重算和容差比较。
- 离线时手动仿真、整定、存储继续可用。AI 未配置或接口失败时如实显示状态，不替换为假回复。

## 视觉边界

第一版按用户已选的“深色工程工作台”实现；1.0.0 增加三维实验档案主页，2.0.0 将其几何替换为程序化信号匣并加入独立傅里叶演示；2.0.1 将明暗主题同步到全部业务页与浮窗。主题变量、公共组件、功能模块、计算和 AI 服务分离，预留修改与扩展入口，避免视觉修改牵动数值逻辑。后文各版本增量按时间记录，当前行为以最新增量为准。

## 验收标准

| 项目 | 通过依据 | 本地测试不能替代的证据 |
|---|---|---|
| 流程贯通 | 四个案例均可配置、运行、比较、记录和复现 | 真实学生可用性试用 |
| 计算可信 | 一阶、二阶解析校验；非法输入、闭环不稳定、观察不足、零目标和扰动边界覆盖 | 真实工业设备辨识或硬件验证不属于首版 |
| AI 实际作用 | 工具调用协议、候选实算、最多三组、版本校验、错误处理测试 | 使用用户实际模型账号的联网验证，及有／无 AI 的学生对照试用 |
| 结果可复现 | JSON 往返、参数与引擎版本、种子、曲线和指标容差验证 | 跨平台或跨引擎版本的一致性另测 |
| 桌面交付 | 完整 EXE 安装包安装与升级、独立启动、真实 Electron 桥调用、路径含中文、数据持久化 | 未经测试的其他电脑／Windows 版本 |
| 开放成果 | 源码、案例、测试脚本、真实测试报告、第三方许可和运行说明 | 团队确认开源许可证、公开仓库、最终参赛材料和真实试用记录 |

参赛截止时间需以报名方向的官网通知为准，软件不内置倒计时。本轮开发和自动化测试不代表比赛评审、真实学习效果或国赛获奖保证。

## 1.0.0 已确认的增量（2026-10-28）

用户将本次主页与视觉更新命名为 1.0.0。基于 RhineLabUI 增加三维实验档案主页，启动直接进入阵列；没有音频和开场片头。保留档案抽取、归位、浏览、材质切换和 360° 查看，详情内容映射到四个真实实验，再进入原计算工作台。

UI 参考其细线、布局、文字层级和交互，配色在原蓝灰主题上微调。实验与计算边界不变。主页、工作台与服务分离，返回主页先完成保存，继续实验保留状态。发布提供完整 Windows EXE 安装包，默认更新桌面固定程序位置，保留用户数据。每版保留 Git 提交、版本标签和发行包，支持按明确版本回退。

## 2.0.0 已确认的增量（2026-10-28）

三维实验入口改为本项目编写的程序化信号匣。阵列与详情共享同一几何定义，采用平顶大矩形屏、顶部信息条、L 形金属边与右上角标签片。继续支持四实验浏览、抽取、归位及进入原工作台；移除 360° 查看入口。旧版 `archive-cassette.glb` 和 `archive-assembly.glb` 不再随本版发行。

信号匣以独立合成信号演示真实傅里叶分析：在 2 秒内均匀采样 256 点，对采样值计算 DFT，提取三个主要分量的频率、幅值和相位，并在同一时间轴重建波形、计算重建误差。屏幕分解与右侧解析文字同步。各实验可以对应不同演示信号，但这些信号不代表各对象的 PID 响应、实际运行记录或学习效果证据。

应用版本为 `2.0.0`，控制计算引擎 `ENGINE_VERSION` 保持 `1.0.0`。原有控制实验、数据保存与 API 边界不变。新增几何与信号演示属于本项目实现；上游 RhineLabUI 场景、交互和界面代码仍有复用，保留作者署名、固定来源及 MIT 许可，不将整个 UI 或全部交互作为原创申报。实际测试和发行结论由验证记录给出。

## 2.0.1 已确认的增量（2026-10-28）

明暗主题以主页选择为起点，统一作用于主页、实验工作台、实验库、我的实验、开放与验证、AI 浮窗及模型设置。浅色沿用主页的暖米白纸面（`#e8e5e1`）、深色文字、暖灰细线，蓝色用于按钮与选中状态，覆盖全部业务页。曲线、坐标与辅助线随主题调整，蓝色当前方案和紫色固定对照的含义不变。

主页设置与“模型与本机设置”均可切换全局明暗，两个入口保持同步。升级继承旧版已保存的主页选择，重启后保留。应用版本更新为 `2.0.1`，控制计算引擎 `ENGINE_VERSION` 保持 `1.0.0`，原有实验存储格式与 API 边界不变。主题、重启保留及安装升级的通过结论待实际验证后记录。

## 2.1.0 已确认的增量（2026-10-29）

主页阵列页的档案编号、实验名称与“查看实验”按钮整体上移，减轻文字与背景较深模型边缘的重叠。实验索引与收藏面板右下角共用的“打开列表形式的实验库 →”入口字号由继承的 9 px 增至 12 px，提升可读性。沿用现有深浅配色、三维信号匣、实验内容和转场。

未保存过明暗偏好时默认使用浅色；主页设置与模型设置仍可切换深色，手动选择保持同步并在重启后保留。升级保留已有明暗偏好。

应用版本更新为 `2.1.0`，控制计算引擎 `ENGINE_VERSION` 仍为 `1.0.0`。控制计算、实验保存和 API 服务边界不变；布局及发行安装结论以本版实际验证记录为准。

## 2.2.0 已确认的增量（2026-10-29）

恢复信号匣阵列出现的入场段，跳过原品牌 Logo、欢迎和身份动画。保留 2.0 的自研大屏信号匣，主页阵列和详情共享模型，傅里叶解析过程与右侧文字继续同步。入场可跳过，减少动态直接完成，实验台返回主页不重播。

加入 MIT 授权的合成交互音效与原创《观测室》循环配乐。由软件外层单一音频服务管理，主页、实验库和工作台共享同一播放进度；设置提供总声音开关、分项开关和音量，立即保存并在重启后保留。重新程序合成打字声，不纳入原片音频采样。应用版本为 2.2.0，计算引擎和实验存储格式不变。

## 3.0.0 已确认的增量（2026-10-29）

采用用户在“logo设计”会话确认的收敛环 Logo 及欢迎段，原始交付位于工作区 `output/design/logo-welcome-01`。欢迎保留约 8 秒的复合波、分量拆分、阻尼响应和收敛环定格四阶段，使用现有明暗主题。它是独立品牌视觉演示，不读取实验数据，不把分解波形视为系统收敛的原因，也不替代工作台真实计算。

启动顺序为欢迎、现有自研信号匣阵列入场、主页；阵列及详情继续使用同一新信号匣模型。欢迎和阵列分别可跳过，减少动态直接进入主页，返回主页不重播开场。欢迎仅配少量主题合成音效，欢迎和阵列期间均不播放背景配乐；主页准备就绪后开始配乐，之后跨主页与实验台连续循环。已有静音、分项开关与音量偏好继续生效并保留。

正式程序、安装器、窗口、桌面快捷方式及软件内品牌标记统一为收敛环 Logo。应用版本为 `3.0.0`，计算引擎仍为 `1.0.0`，原有实验数据、API 边界和存储格式不变。欢迎、音频、图标及安装升级的通过结论以本版实际验证记录为准，历史参赛报告保留其原版本与证据范围。
