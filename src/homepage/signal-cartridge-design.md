# 控小助 2.0.0 信号匣几何

该模型由 `signal-cartridge.ts` 的二维轮廓、挤出几何和基础长方体独立生成。旧 GLB 仅用于读取世界坐标包围盒，以保留既有阵列间距与摄像机取景；没有复用其网格、纹理、标志或双圆环结构。

## 外形与屏幕

- Y 轴向上，正面朝 +Z。外包围盒：`[-2.5, 0, -0.13]` 至 `[2.51039, 3.7, 0.2464]`。
- 哑光浅蓝灰薄壳、独立左下 L 形金属边、右上带七条槽纹的小凸片、底部状态条与三个细槽。
- 按用户最后的红笔修订，屏幕上边缘全宽齐平，顶部信息区与大屏水平分隔。已取消先前的右上阶梯延伸。
- 屏幕宽 `4.26`、高 `2.38`，左下 `[-2.035, 0.445]`，右上 `[2.225, 2.825]`，正面 Z 为 `0.233`。屏幕无模糊与透射；没有覆盖整个正面的玻璃盖。
- 信息贴片中心 `[-0.695, 3.182, 0.224]`，宽 `2.49`、高 `0.43`，位于屏幕外上方。

## 集成 API

- `createSignalCartridgeParts()`：一次创建六组直接可供 Mesh / InstancedMesh 使用的烘焙几何。所有组均为 `array: true`，因此阵列与详情模型一致。
- `createSignalScreenShape(expand = 0)`：提供单一圆角矩形屏幕轮廓，扩大量用于边框。
- `createSignalScreenGeometry(z = 0.234)`：供调用方叠加傅里叶 CanvasTexture 的屏幕平面。归一化 UV 覆盖完整屏幕；正常 CanvasTexture 保持默认 `flipY = true`。
- `SIGNAL_SCREEN`、`SIGNAL_LABEL`、`SIGNAL_CARTRIDGE_BOUNDS`：屏幕、信息贴片及外包围盒参数。
- 新几何不需要纹理文件或 GLB。文字、屏幕波形与解析动画由调用方绘制。

## 默认浅色材质

| 名称 | 颜色 | metalness | roughness | 投影 |
| --- | --- | --- | --- | --- |
| Signal_Shell | `#c9d3de` | 0.38 | 0.49 | 是 |
| Signal_Trim | `#acbbc9` | 0.82 | 0.28 | 是 |
| Signal_Recess | `#33495e` | 0.44 | 0.40 | 是 |
| Signal_Screen | `#091421` | 0.12 | 0.30 | 否 |
| Signal_Accent | `#7198c3` | 0.42 | 0.35 | 否 |
| Signal_Marks | `#6c7f92` | 0.30 | 0.52 | 否 |

屏幕另设 clearcoat `0.22`、clearcoatRoughness `0.26`。外壳不透明。主题可根据以上独立名称映射暗色材质。

几何自检：六批共 `3,194` 个三角形；所有顶点、法线和 UV 为有限数值。实际浮点包围盒与旧资产包围盒最大误差小于 `3 × 10⁻⁷`。曲线与文字不包含在几何面数中。
