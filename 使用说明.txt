控小助 AI 控制实验工作台 3.0.0 — Windows x64

一、安装与更新
双击“控小助-3.0.0-安装包.exe”，按提示完成安装，之后从桌面“控小助”快捷方式启动。发给同学只需发送这个完整安装包，不需要单独发送 DLL 或安装 Node.js、Python。
更新前正常关闭软件，再运行新安装包，保留默认的原安装位置。实验和设置保存在当前 Windows 用户的应用数据目录，覆盖程序与卸载程序不会主动删除这些记录。

二、主页怎么用
启动后先播放约 8 秒的控小助欢迎段，淡出后接入原有约 4.6 秒信号匣阵列入场。“跳过欢迎”或 Esc 只跳过当前欢迎段，阵列入场仍可单独跳过；减少动态效果时直接进入主页。上下按钮、上下方向键和滚轮会依次选择全部四个实验，计数显示为 01／04 至 04／04；左右方向键切换分组。也可以拖动信号匣阵列或点击右上角“实验索引”。回车或“查看实验”抽出当前信号匣，右侧可以查看同步信号解析、实验任务、学习目标与模型边界，点击“开始实验”进入工作台。
欢迎段采用已经确认的收敛环 Logo，依次展示复合波、分量拆分、阻尼响应和品牌定格。这是独立视觉演示，不是实际仿真结果，也不表示分解波形就能使系统收敛。软件、安装程序、窗口、桌面快捷方式和软件内品牌图标同步使用这一 Logo。
2.1.0 将阵列页的档案编号、实验名称和“查看实验”按钮整体上移，减轻文字与背景较深模型边缘的重叠；实验索引与收藏面板右下角“打开列表形式的实验库 →”入口的字号从 9 px 增至 12 px。主题配色、模型与转场保持不变。
信号匣采用平顶大矩形屏、顶部信息条、L 形金属边和右上角标签片，阵列与详情使用同一几何。按 Esc 返回总览；2.0.0 已移除 360° 查看。
匣内波形是独立合成信号的傅里叶教学演示：从采样值计算 DFT 后提取频率、幅值与相位，再重建波形，右侧文字随解析进度同步显示。它不是 PID 实验的实际数据。控制系统响应和性能指标请到工作台运行仿真后查看。
“我的实验”打开历史记录；“继续当前实验”返回当前工作台。主页设置提供显示质量、明暗与减少动态效果，未保存过明暗偏好时默认浅色，默认使用流畅画质。可在设置中切换深色，选择会记住并在重启后保留；升级保留已有明暗偏好。不播放上游品牌片头。3.0.0 的欢迎段只配少量轻音效，欢迎和阵列入场期间不播放背景配乐，主页准备就绪后才播放；进入实验台后同一配乐连续播放，不从头开始；返回主页也不重播欢迎或阵列入场。
主页设置与“模型与本机设置”均有声音总开关，并可分别关闭背景配乐、交互音效或打字反馈、调整音量；设置立即保存，重启保留。保存的静音和交互音效开关同样适用于下次启动的欢迎段。
2.0.1 的明暗选择在主页、工作台、实验库、我的实验、开放与验证、AI 浮窗及模型设置之间同步。浅色沿用主页的暖米白纸面、深色文字、暖灰细线，蓝色用于按钮与选中状态；图线颜色随主题调整，蓝色仍表示当前方案，紫色仍表示固定对照。升级会继承旧版已保存的主页明暗选择，重启后保留。

三、第一次完整实验：电机调速
1．在主页找到“电机调速”，查看任务和模型假设，点击“开始实验”。
2．先运行默认参数，观察蓝色响应曲线、目标虚线和五项性能指标。初始教学参数有意保留待改进问题。
3．在“预测与复盘”写下预测。例如：“增大积分 Ki 后，稳态误差会减小，但可能增加超调。”
4．返回“响应与指标”，左侧只改一个参数，再点“运行仿真”。观察曲线和指标变化。紫色虚线作为固定对照，自动预览不会覆盖它；下一次用不同参数手动确认后更新对照。
5．进入“方案对比”，使用自动整定生成计算对照，比较响应速度、超调、误差和控制输出的代价。应用前核对结果。
6．需要 AI 时，点击“AI 助手”（常规窗口右下角，较矮窗口导航栏右侧）。先填写自己的 API 设置，然后描述问题，等候候选实算，检查依据后再决定是否应用。没有密钥也能完成前面所有步骤。
7．在“预测与复盘”记录观察、结论和取舍；在“运行记录”导出 JSON 实验包或 HTML 小结。实验自动保存，返回主页后可通过“我的实验”恢复。

四、配置模型
在主页设置中打开“模型与 API 设置”，或者在工作台点击“模型与设置”。默认服务地址为 https://api.deepseek.com，模型名称可编辑。填写自己账号可用的模型及密钥，保存后测试连接。
“模型与本机设置”中也可以切换全局明暗主题，选择与主页设置同步。
密钥只在本机填写，实验包不包含密钥。连接测试会发送一次小请求，可能计入账号用量。AI 仅在你请求时调用，会发送当前模型、目标、参数、问题和必要结果上下文，不主动上传整个本地文件夹。
模型未配置或网络不可用时，手动仿真、整定、保存与复算仍可使用。

五、理解指标与迁移
“无法判定”表示当前证据不足，应展开“每项指标的判定依据”查看原因。调节时间可能因观察窗口不足无法得到；理论稳态误差与有限时间末端误差不同。没有启用扰动时，扰动恢复时间显示“不适用”。搜索未找到达标参数不等于数学上无解。
迁移到另一台电脑时，导出 JSON 实验包并重新导入；CSV 是曲线数据，HTML 是可阅读小结。模型密钥在新电脑重新填写。

六、边界
本软件使用简化教学模型，不连接真实硬件。自定义对象限稳定连续单输入单输出、严格真有理、正稳态增益、最高三阶；不含账号、云同步、纯滞后、多变量或硬件控制。
应用版本为 3.0.0；控制计算引擎仍为 1.0.0。收敛环 Logo 与欢迎段来自本项目经用户确认的设计交付，原始文件位于设计工作区 output/design/logo-welcome-01。新信号匣几何由本项目程序化生成，主页仍包含改编的 RhineLabUI 代码，署名与 MIT 许可见“第三方许可”。旧版两份 GLB 模型不再随本版发行，本版仍使用自研大屏信号匣及傅里叶解析。音效和《观测室》配乐按上游 MIT 许可复用；未使用原片打字采样。
测试记录见 VALIDATION.md。未验证实际 DeepSeek 账号、真实学生学习效果或所有 Windows 电脑。本安装包未做公开代码签名。
